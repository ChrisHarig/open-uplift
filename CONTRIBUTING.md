# Contributing to Open Uplift

Thanks for your interest in contributing!

## Getting Started

The easiest way to contribute is to open an issue — bug reports, feature requests, and questions are all welcome.

If you'd like to contribute code:

1. Fork the repo and create a branch
2. Make your changes
3. Run tests: `make test`
4. Open a pull request
