# Changelog

## 0.1.0 — 2025-03-06

Initial release.

- Session ingestion from Claude Code and Codex CLI
- LLM transcript compaction and judge evaluation
- Uplift factor computation (per-session, per-project, aggregate)
- Web dashboard with charts, session browser, and transcript viewer
- Full CLI for all operations
- Configurable judge/compaction prompts with output schemas
- Self-report surveys (CLI and dashboard)
- Organization hubs with push/pull sync
- Sharing config for controlling what data members share
- Scheduled batch processing (sync + judge)
- CSV and JSON export
- Docker support
- Claude Code plugin with survey skill
